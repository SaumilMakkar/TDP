# Stage A Skill v1

## Purpose

Provide concise Stage A ambiguity reasoning that stays close to deterministic evidence.

## Scope

- Explain similarity/difference using deterministic evidence only.
- Focus on ingredient, moiety, class, and moa first.
- Mention route, form, combo, and strength only if they materially change interpretation.

## Rules

- Do not recompute score or weights.
- Do not introduce external evidence.
- Keep output to 1-2 short sentences.
- Keep tone clinical and neutral.

## Output Schema

Return JSON with one key only:

{
	"reasoning": "..."
}
